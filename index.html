Synchronisation automatique

Tes recettes sont enregistrées sur cet appareil uniquement. Active la synchronisation pour les conserver dans un espace privé de ton compte GitHub : elles se retrouveront sur tous tes appareils, et survivront à un changement de téléphone.

Comment obtenir ma clé GitHub ? (2 minutes)
  1. Va sur github.com/settings/tokens/new (connecte-toi si besoin).
  2. Dans Note, écris : Livre de recettes.
  3. Dans Expiration, choisis No expiration — sinon la synchro s'arrêtera toute seule dans quelques mois.
  4. Dans la liste des cases à cocher, coche uniquement gist.
  5. Descends tout en bas, clique Generate token.
  6. Copie la clé affichée (elle commence par ghp_) et colle-la ci-dessus. GitHub ne la réaffichera plus, garde-la aussi dans tes notes.

Cette clé ne donne accès qu'à tes gists, rien d'autre. Elle reste dans ce navigateur.
