## 9. Commentaire type "Smart Commenting"

### Commentaire de valeur pure
```
Je creuse ton point [X] — chez [exemple concret] on voit plutôt
[angle différent / chiffre]. Tu as observé la même tendance ?
```

### Commentaire à contradiction douce
```
D'accord sur [point A], moins sur [point B] : dans mon expérience
avec [niche], c'est souvent [argument opposé]. Curieux de ton
raisonnement derrière.
```

### Commentaire "ajoute du contexte"
```
Un détail qui change tout ici : [insight précis]. Les gens sous-
estiment à quel point ça modifie [conséquence].
```

**Jamais** : "Great post!", "So true!", "This 🔥".
